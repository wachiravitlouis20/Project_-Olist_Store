# SQL Project : Olist Store Analysis
## Project Objective
This project performs a comprehensive analysis of the Brazilian E-commerce Public Dataset by Olist. The primary goal is to leverage advanced SQL techniques to uncover actionable insights across sales, customer behavior, and logistics. The final output provides strategic recommendations to enhance business performance, improve customer satisfaction, and drive profitability.

# Description
this Projects use SQL to analyze dataset of Olist store The goal of the project is to answer a set of questions about the store's business performance and help in its growth by making better decisions.

# Business Questions
This analysis seeks to answer key business questions across several domains:

### Product & Sales
* What are the monthly sales trends and overall growth patterns?
* Which product categories generate the most revenue?
* What are the top 3 best-selling products within each category?
* What is the Average Order Value (AOV), and how does it differ by payment method?

### Customer Behavior
* Which states are the primary markets, and what is their month-over-month growth?
* How can we segment customers using RFM Analysis to identify high-value groups?
* What is the average time between a customer's first and second purchase?
* What is the average customer value (LTV proxy) for each RFM segment?

### Logistics & Satisfaction
* What is the average delivery time, and what is the on-time vs. late delivery rate?
* How does delivery time correlate with customer review scores?
* Which seller states are the most efficient at preparing orders for shipment?
